# 📜 Shared API & Database Contracts

This document serves as the single source of truth for both **Nishit** (Frontend) and **Tanish** (Backend).

---

## 💾 MongoDB Schema Specifications

### 1. User Schema
```json
{
  "_id": "ObjectId",
  "name": "String",
  "email": "String (unique)",
  "password": "String (hashed)",
  "role": "String ('REPORTER' | 'ADMIN')",
  "createdAt": "ISODate"
}
```

### 2. Report Schema
```json
{
  "_id": "ObjectId",
  "userId": "ObjectId (ref: User)",
  "description": "String (required)",
  "image": "String (URL, optional)",
  "location": {
    "address": "String",
    "coordinates": {
      "lat": "Number",
      "lng": "Number"
    }
  },
  "emergencyType": "String (optional: Fire, Medical, Accident, Security, Natural Disaster, Other)",
  "incidentId": "ObjectId (ref: Incident, optional - linked after AI processing)",
  "createdAt": "ISODate"
}
```

### 3. Incident Schema
```json
{
  "_id": "ObjectId",
  "type": "String ('Fire' | 'Medical' | 'Accident' | 'Security' | 'Natural Disaster' | 'Other')",
  "severity": "String ('LOW' | 'MEDIUM' | 'HIGH' | 'CRITICAL')",
  "location": {
    "address": "String",
    "coordinates": {
      "lat": "Number",
      "lng": "Number"
    }
  },
  "summary": "String (Generated by AI)",
  "status": "String ('REPORTED' | 'VERIFIED' | 'RESPONDING' | 'RESOLVED')",
  "reportCount": "Number",
  "reportIds": ["ObjectId (ref: Report)"],
  "createdAt": "ISODate",
  "updatedAt": "ISODate"
}
```

## 🌐 REST API Endpoints Specification

### Authentication APIs

#### `POST /api/auth/register`
- **Request Body**:
  ```json
  {
    "name": "Jane Doe",
    "email": "jane@example.com",
    "password": "securepassword",
    "role": "REPORTER"
  }
  ```
- **Response `201 Created`**:
  ```json
  {
    "token": "JWT_TOKEN_STRING",
    "user": { "id": "123", "name": "Jane Doe", "role": "REPORTER" }
  }
  ```

#### `POST /api/auth/login`
- **Request Body**:
  ```json
  {
    "email": "admin@emergency.ai",
    "password": "adminpassword"
  }
  ```
- **Response `200 OK`**:
  ```json
  {
    "token": "JWT_TOKEN_STRING",
    "user": { "id": "456", "name": "Admin User", "role": "ADMIN" }
  }
  ```

---

### Emergency Reports APIs

#### `POST /api/reports`
- **Headers**: `Authorization: Bearer <JWT_TOKEN>`
- **Request Body**:
  ```json
  {
    "description": "Smoke coming from Block B first floor window",
    "location": {
      "address": "Block B, First Floor",
      "coordinates": { "lat": 12.9716, "lng": 77.5946 }
    },
    "emergencyType": "Fire"
  }
  ```
- **Response `201 Created`**:
  ```json
  {
    "message": "Report submitted successfully. Processing incident summary...",
    "report": { "_id": "rep_101", "description": "...", "status": "processing" }
  }
  ```

---

### Incident Management APIs (Admin)

#### `GET /api/incidents`
- **Headers**: `Authorization: Bearer <ADMIN_JWT_TOKEN>`
- **Response `200 OK`**:
  ```json
  {
    "stats": { "total": 24, "active": 8, "critical": 2 },
    "incidents": [
      {
        "_id": "inc_501",
        "type": "Fire",
        "severity": "HIGH",
        "location": { "address": "Block B, First Floor" },
        "summary": "Multiple reports indicate a possible fire on the first floor of Block B.",
        "status": "REPORTED",
        "reportCount": 3,
        "createdAt": "2026-08-19T20:00:00Z"
      }
    ]
  }
  ```

#### `GET /api/incidents/:id`
- **Headers**: `Authorization: Bearer <JWT_TOKEN>`
- **Response `200 OK`**: Returns single incident object including full list of original user reports.

#### `PATCH /api/incidents/:id/status`
- **Headers**: `Authorization: Bearer <ADMIN_JWT_TOKEN>`
- **Request Body**:
  ```json
  { "status": "RESPONDING" }
  ```
- **Response `200 OK`**:
  ```json
  { "message": "Incident status updated to RESPONDING", "incident": { ... } }
  ```
